Tigerd is an AI coding IDE built for developers worldwide.

Use AI agents on your codebase, checkpoint and visualize changes, and bring any model or host locally. Tigerd routes messages through a managed backend without retaining your code.

This repo contains the full distribution source code for Tigerd. If you're new, welcome!

- 🌐 [Website](https://tigerd.dev)
- 👋 [Discord](https://discord.gg/tigerd)
- 🐛 [Issues](https://github.com/miiglu/tigerd/issues)
- 📦 [Releases](https://github.com/miiglu/tigerd-binaries)

## Reference

Tigerd is built on these open source foundations:

- [Void Editor](https://github.com/voideditor/void) — Apache-2.0
- [OpenCode](https://github.com/sst/opencode) — MIT
- [VS Code](https://github.com/microsoft/vscode) — MIT

For a guide to the codebase see [TIGERD_CODEBASE_GUIDE](https://github.com/miiglu/tigerd/blob/main/TIGERD_CODEBASE_GUIDE.md).

For a guide on building your own version see [tigerd-builder](https://github.com/miiglu/tigerd-builder).
